# Muthur Command multicast plugin

中文文档: [`README.zh-CN.md`](./README.zh-CN.md)

Supervisor-managed **multicast** add-on for **Muthur Command OS**, published as **`ghcr.io/muthur-command/{arch}-mcio-multicast`** (multi-arch manifest **`mcio-multicast`**).

Built on **`ghcr.io/muthur-command/base`**; OCI labels use **`io.mcio.*`**.

## Origin

- **Upstream:** [home-assistant/plugin-multicast](https://github.com/home-assistant/plugin-multicast) — Home Assistant Supervisor multicast plugin container, from which this tree was ported.
- **In this repo:** **Muthur Command** keeps this fork for **Muthur Command OS**; behavior may diverge from upstream over time.
